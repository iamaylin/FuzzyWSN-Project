
# FuzzyWSN: Secure and Energy-Aware Routing

## Overview

This project investigates fuzzy logic-based routing
decisions in Wireless Sensor Networks (WSNs).

The study focuses on reproducing the Interval Type-2
Fuzzy Logic routing subsystem described in the
reference paper and experimentally comparing it
with a Type-1 Fuzzy Logic approach.

## Reference Paper

A secure and energy-efficient routing using coupled
ensemble selection approach and optimal type-2
fuzzy logic in WSN.

Scientific Reports (2025).

## Objectives

1. Implement a simplified WSN simulation.
2. Reproduce the selected IT2FLS routing subsystem.
3. Implement a Type-1 fuzzy comparison model.
4. Evaluate both approaches under controlled
   network conditions and uncertainty.
